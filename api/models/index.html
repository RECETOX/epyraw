    Models API#

    epyraw.models #

    Data models for Thermo RawFile Reader.

    These classes provide Pythonic data structures for representing spectrum, chromatogram, and other mass spectrometry data.

    Spectrum dataclass #

    Mass spectrum data.

    Represents a single mass spectrum with mass-to-charge ratios and corresponding intensities.

    base_peak property #

    Return the base peak as (m/z, intensity).

    charges = None class-attribute instance-attribute #

    Array of charge states (only for centroid/label data).

    intensities = field(default_factory=(lambda: np.array([], dtype=(np.float64)))) class-attribute instance-attribute #

    Array of intensity values.

    intensity_range property #

    Return the intensity range (min, max).

    is_centroid = True class-attribute instance-attribute #

    Whether this is centroid (peak list) or profile data.

    mass_range property #

    Return the mass range (min, max).

    masses = field(default_factory=(lambda: np.array([], dtype=(np.float64)))) class-attribute instance-attribute #

    Array of m/z values.

    num_peaks property #

    Number of peaks in the spectrum.

    scan_number = 0 class-attribute instance-attribute #

    The scan number this spectrum corresponds to.

    total_ion_current property #

    Return the total ion current (sum of all intensities).

    __len__() #

    Return the number of peaks.

    __repr__() #

    Return a string representation.

    to_pandas() #

    Convert to pandas DataFrame.

    Returns:

    Type Description
    DataFrame

    DataFrame with columns 'mass', 'intensity', and optionally 'charge'.

    Chromatogram dataclass #

    Chromatogram data.

    Represents a chromatographic trace with retention times and corresponding intensities.

    base_peak_intensity property #

    Return the intensity of the base peak.

    base_peak_time property #

    Return the retention time of the base peak.

    intensities = field(default_factory=(lambda: np.array([], dtype=(np.float64)))) class-attribute instance-attribute #

    Array of intensity values.

    intensity_range property #

    Return the intensity range (min, max).

    mass_range = None class-attribute instance-attribute #

    Mass range used for extracted ion chromatograms.

    num_points property #

    Number of points in the chromatogram.

    time_range property #

    Return the time range (start, end) in minutes.

    times = field(default_factory=(lambda: np.array([], dtype=(np.float64)))) class-attribute instance-attribute #

    Array of retention times (in minutes).

    total_ion_current property #

    Return the total ion current (integral of intensities).

    trace_type = 0 class-attribute instance-attribute #

    Type of chromatogram (TraceType enum value).

    __len__() #

    Return the number of points.

    __repr__() #

    Return a string representation.

    to_pandas() #

    Convert to pandas DataFrame.

    Returns:

    Type Description
    DataFrame

    DataFrame with columns 'time' and 'intensity'.

    ScanHeader dataclass #

    Detailed scan header information.

    Provides metadata about a specific scan including MS level, precursor info, and acquisition parameters.

    collision_energy = 0.0 class-attribute instance-attribute #

    Collision energy in eV.

    instrument_model = '' class-attribute instance-attribute #

    Instrument model that acquired the scan.

    isolation_width = 0.0 class-attribute instance-attribute #

    Isolation width in Da.

    ms_level = 1 class-attribute instance-attribute #

    MS level (1 for full scan, 2 for MS/MS, etc.).

    number_of_ions = 0 class-attribute instance-attribute #

    Number of ions/peaks detected.

    precursor_scan_num = 0 class-attribute instance-attribute #

    Precursor scan number for MSn scans.

    scan_number = 0 class-attribute instance-attribute #

    The scan number.

    scan_type = '' class-attribute instance-attribute #

    Type of scan (e.g., 'Full', 'SIM', 'ProductIon').

    trigger_time = 0.0 class-attribute instance-attribute #

    Trigger time in minutes.

    __repr__() #

    Return a string representation.

    ScanEvent dataclass #

    Scan event information including reactions.

    Provides access to reaction data for MSn scans, including mass analyzer settings and reaction parameters.

    mass_analyzer = 0 class-attribute instance-attribute #

    Mass analyzer type identifier.

    reactions = field(default_factory=list) class-attribute instance-attribute #

    List of reactions for this scan event.

    __repr__() #

    Return a string representation.

    Reaction information for MSn scans.

    Contains precursor mass, collision energy, and isolation width for a single reaction step.

    collision_energy = 0.0 class-attribute instance-attribute #

    Collision energy in eV.

    isolation_width = 0.0 class-attribute instance-attribute #

    Isolation width in Da.

    precursor_mass = 0.0 class-attribute instance-attribute #

    Precursor mass in Da.

    __repr__() #

    Return a string representation.

    MassOptions dataclass #

    Options for mass precision operations like scan averaging.

    Configures tolerance settings for matching peaks across spectra.

    tolerance = 5.0 class-attribute instance-attribute #

    Tolerance value.

    tolerance_units = 1 class-attribute instance-attribute #

    Units for tolerance (0=Daltons, 1=ppm). Matches ToleranceUnits enum.

    __repr__() #

    Return a string representation.

    RawFile API#

    epyraw.raw_file #

    Main RawFile class for reading Thermo .raw files.

    RawFile #

    Wrapper around Thermo RawFileReader's IRawDataPlus interface.

    Provides a Pythonic interface to read Thermo Scientific .raw mass spectrometry files.

    Example

    from epyraw import RawFile, Device with RawFile("data.raw") as rf: ... rf.select_instrument(Device.MS, 1) ... print(f"Scans: {rf.run_header.spectra_count}") ... spectrum = rf.get_spectrum(100) ... print(f"Peaks: {spectrum.num_peaks}")

    average_scans(scan_numbers, options=None) #

    Average an arbitrary list of spectra.

    Note: This functionality requires the AverageScans method which may not be available in all library versions. If not available, returns an empty spectrum.

    Parameters:

    Name Type Description Default
    scan_numbers list[int]

    List of scan numbers to average.

    		 required
    options MassOptions | None

    Mass tolerance options. If None, uses defaults.

    		 None

    Returns:

    Type Description
    Spectrum

    Averaged Spectrum object, or empty spectrum if feature unavailable.
    Example

    with RawFile("data.raw") as rf: ... rf.select_instrument(Device.MS, 1) ... scans = [100, 102, 104, 106] ... avg = rf.average_scans(scans)

    		 required

    		 None

    		 None

    set_runtime(runtime) #

    Configure the .NET runtime to use.

    This function must be called before opening any RawFile instances. Once a RawFile is opened, changing the runtime has no effect.

    Parameters:

    Name Type Description Default
    runtime str

    The runtime to use. Options are: - "mono": Use Mono runtime (default on Linux/macOS) - "coreclr": Use .NET Core/.NET 5+ runtime - "netfx": Use .NET Framework (Windows only) - "default": Use pythonnet's default runtime detection

    		 required
    Example

    from epyraw import set_runtime, RawFile set_runtime("mono") # or "coreclr" with RawFile("data.raw") as rf: ... pass
